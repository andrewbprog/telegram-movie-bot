# telegram-bot-service


## Цель сервиса
Telegram Bot Service служит интерфейсом для взаимодействия пользователей с платформой через мессенджер Telegram. Сервис обрабатывает команды от пользователей, создает записи пользователей в своей базе данных, взаимодействует с API Gateway для получения фильмов и рекомендаций, а также обрабатывает события из Kafka для уведомления пользователей о новых рекомендациях.

---

## Стек технологий

- Go 1.23 - основной язык разработки
- Zap - структурированное логирование
- PostgreSQL 15 - основная база данных
- Docker & Docker Compose - контейнеризация
- Kafka - брокер сообщений

---

## Инфраструктура
В проекте используется **Docker Compose**, который поднимает:
- `telegram_bot_service` — основной сервис.
- `postgresql` — база данных для хранения пользователей.
- `zookeeper` — для обеспечения распределенной синхронизации данных.
- `kafka` — брокер для обработки данных в реальном времени.
